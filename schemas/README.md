# Schemas

Schemas conserves pour le workflow device-only :

- `telemetry.v1.schema.json` : records de telemetrie envoyes par un boitier.
- `prediction.v1.schema.json` : sortie technique maintenance/securite.
- `intervention.v1.schema.json` : brouillon d'intervention terrain.
- `solar_advisor.v1.schema.json` : recommandation de kit solaire.

Les schemas actifs sont limites au workflow device, prediction et intervention.
