# Scripts

Scripts utiles pour le MVP device-only :

- `simulate_realtime_stream.py` et `simulate_fleet_realtime.py` envoient des records de telemetrie.
- `demo_telemetry_api.py` teste les endpoints d'ingestion et de prediction.
- `predict_device_cli.py` lance une prediction locale sur un device.
- `demo_pipeline.py` regenere les modeles locaux de demonstration.
- `generate_synthetic_data.py` regenere le dataset MVP.
- `demo_solar_advisor.py` teste le module Solar Advisor.

Les scripts actifs envoient uniquement des records de telemetrie lies a un device.
